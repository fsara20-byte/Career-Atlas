Enable automatic job updates

One-time GitHub setup. Afterwards, a scheduled workflow updates the job data file and your GitHub Pages site displays it when refreshed.

0 / 6 complete
Important: This does not automatically scan all 194 employer and business-unit pages. The included updater checks five documented official public Greenhouse recruitment boards (Schonfeld, Addepar, Teneo, Guidepoint and Third Bridge); some may return no roles matching your finance/strategy filters. The other employer portals, including most banks, are NOT automatically checked by this GitHub workflow. Your independent ChatGPT alert monitors additional companies.

1. Download the GitHub deployment package

Download the accompanying career-watch-deploy.zip file from ChatGPT and unzip it. It includes this website, official job-feed configuration and the scheduled update workflow.

Keep .github/workflows intact. On a Mac, press Command + Shift + . in Finder to show hidden folders.

2. Create a new GitHub repository

Open github.com/new ↗, name your repository career-watch-2027, select Public, then click Create repository. Leave the README box unchecked.

Use a separate repository from your CFA tracker.

3. Upload all the files, including the hidden workflow folder

Open GitHub Desktop ↗ and choose File → Clone repository. Select the empty repository you just created. Copy all files and folders from the unzipped package into that cloned folder (including the hidden .github folder). Return to GitHub Desktop, commit the files and click Push origin.

Prefer Terminal? Show commands

Open Terminal inside the unzipped project folder, then run:

git init
git add .
git commit -m "Initial career watch"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/career-watch-2027.git
git push -u origin main
Replace YOUR_USERNAME with your GitHub username.

4. Turn on GitHub Pages

In your repository: Settings → Pages → Build and deployment → Deploy from a branch. Choose main and /(root); press Save.

Your public site will be https://YOUR_USERNAME.github.io/career-watch-2027/

5. Run the first automatic check

Go to Actions → Update official job feeds → Run workflow → Run workflow. Once it finishes, open data/jobs.json in your repository to confirm new jobs and the lastSuccessfulAt time are present.

The scheduled workflow checks daily around 08:17 Dubai time (GitHub may delay runs).

6. Open the live website and protect your notes

Visit your GitHub Pages URL. Refresh the browser to load new vacancies. Click Notes and create a JSON backup of your personal applications. Keep this backup private.

Do not upload your notes or application backup into a public GitHub repository. Notes stay in each browser/device unless you import your backup.

After setup: what updates automatically?

Automatic
Matching vacancies found on enabled public Greenhouse feeds; posting links, locations, publish dates and last checked times.
Not automatic
Unpublished deadlines, employers without compatible feeds, your Applied/Notes fields, or job applications themselves.

Want to add another employer with a supported public Greenhouse or Ashby job board? Add its verified feed in config/sources.json. A generic careers homepage is not an API. Only confirmed published feeds can update automatically. Job-board coverage is not a guarantee of openings or complete eligibility information.
